Diese drei Dateien wurden unverändert aus dem lokalen Vollversions-Build
`soundstorm-full/output/beta-20261011/icons` übernommen. Der Verifier prüft
SHA-256, nicht nur Dateiformat oder Größe.

| `icon.icns` | Originales macOS-Icon | `865636bb1b3f32fcde65d6f5a7b41e1ca56f245edd39d33bab80ab75e28915cb` |

Das Windows-Programm enthält bereits das korrekte eingebettete Icon der
Vollversion. macOS verwendet die identische ICNS-Datei sowie das PNG für das
Dock; Linux übernimmt das PNG. Das Web-Favicon wird nicht als App-Icon verwendet.

`web-demo-manifest.json` dokumentiert die 160 unveränderten Spieldateien aus der
verifizierten öffentlichen Webdemo. Der SHA-256 des Originalmanifests lautet
